DEPUFF — BLACK EDITION

This is a free installable web app (PWA), not an App Store IPA.
It has no subscription, trial, ads, or payment features.

TO INSTALL ON IPHONE:
1. Upload the contents of this folder to a free HTTPS static host, such as GitHub Pages.
2. Open the published https:// address in Safari.
3. Tap Share (square with arrow) > Add to Home Screen > Add.
4. Open DEPUFF from your Home Screen.

The app stores the daily checklist, water count, and sleep check-in locally on the device.
The daily checklist and water count start fresh each calendar day.
